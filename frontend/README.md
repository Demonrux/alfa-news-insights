# Фронтенд: модуль «Аналитика для бизнеса» в Альфа-Бизнесе

Реплика интернет-банка Альфа-Бизнес с нашим модулем: вход, главная с виджетом «События для вашего бизнеса»,
лента инсайтов, карточка инсайта, «Как получен вывод», чат, дайджест. Стек: Next.js 16 (App Router), TypeScript,
Tailwind CSS 4, библиотека компонентов Альфа-Банка `@alfalab/core-components` (MIT, тема `corp`).

## Запуск

```bash
cd frontend
npm install
npm run dev          # http://localhost:3000
npm run build && npm run start   # боевая сборка
npm run lint
```

Нужен Node.js 20 или новее (проверено на 24). Бэкенд для запуска не нужен: пока адрес API не задан
(`NEXT_PUBLIC_API_URL` в `.env`), фронт работает на моках.

Вход в демо: любой телефон и пароль (в том числе пустые).

## Что настоящее, а что мок

| Часть | Статус |
|---|---|
| Экраны, состояния, логика интерфейса | настоящие |
| Данные карточек, ленты, компаний | моки: `src/mocks/data.ts` |
| `src/mocks/card-rate-treasurer.json` | живой вывод модели (p5_interpret, Настя, 22.10.2026) без правок |
| Остальные карточки | синтетические, написаны под `prompts/schemas/insight.json` |
| Вход, последняя компания, роль, скрытые карточки | хранятся в `localStorage` |
| Обращение к менеджеру, обратная связь, чат | заглушки, ничего не отправляют |

Все обращения к данным идут через один слой `src/lib/api.ts`. Когда появится настоящий API, меняется только
тело этих функций. Типы в `src/lib/types.ts` повторяют схему карточки `insight.json`. То, чего в схеме нет
(ID, дата, источники с названиями, признак проверки критиком), лежит в обёртке `CardEnvelope`. Формат обёртки
наше допущение, его должен подтвердить бэкенд.

## Состояния для показа на демо

К любому адресу можно добавить параметр:

- `?demo=denied` нет доступа (403)
- `?demo=limit` лимит исчерпан (429)
- `?demo=error` ошибка загрузки (502)
- `?demo=empty` пустая лента
- `?jury=1` на карточке: в панели «Как получен вывод» появляется вкладка «Отклонённые критиком»

## Структура

```
src/
  app/
    login/                 вход
    (bank)/                оболочка банка (шапка, меню); без входа ведёт на /login
      page.tsx             главная с виджетом
      analytics/           лента, дайджест, разбор своей новости (analyze), карточка (analytics/[id])
  components/
    shell/                 шапка, боковое меню, переключатель компании
    ui/                    иконки, плашки типа события, уровень влияния, типы утверждений, окно, уведомления
    home/ feed/ insight/   виджет, карточка ленты, карточка инсайта, панели «Как получен вывод» и чат
    dialogs/ states/       окна (роль, обращение к менеджеру) и состояния (ошибки, пусто, загрузка)
  lib/                     типы, словари подписей, API-слой, сессия, форматирование
  mocks/                   моки для разработки без бэкенда
```

## Решения по макету и схеме

- Типы утверждений различаются не только цветом, а рамкой, иконкой и подписью: факт, позиция банка, вывод AI,
  гипотеза. Подписи берутся из `prompts/disclaimers.yaml`.
- Карточка не прошла проверку критиком: в ленте не показывается, видна только жюри.
- `overall_impact = neutral` показывается нейтральной плашкой. «Позиция могла устареть» считается по
  `report_date` (порог 60 дней, `isStale` в `src/lib/format.ts`, порог согласуем).
- В интерфейсе 4 роли (финдиректор, казначей, гендиректор, собственник). Остальные значения схемы сводятся к
  ближайшей (`uiRole` в `src/lib/labels.ts`).
- Названия компаний обезличены: «Компания N · вид деятельности · Группа N». Внутренние ID и точные суммы
  на экран не выводятся.
- Дисклеймер и бейдж «Не является позицией банка» берутся из ответа API, а при его отсутствии из словаря.
